# ESSI Hulk Hunting

**EastShire Space Industries · Deep Survey Division**: derelict survey of the UnderPunks RPG solar system.

ESSI field analysts read the public comms traffic of the `#spacecraft` channel and chart what it reveals about
derelict hulls (HULKS): where triangulations resolved them, which sector slices scanners swept empty, which
stations sit where, and how the instruments behave (calibration rolls, cipher quality, jump laws).

- **Chart** (`docs/index.html`): polar map of the 12 sectors (Oc) × distance from the Sun (Rc, in SL). Pan, zoom,
  filter by layer / cipher quality / signaller / date, deep links (`#mrtg-03`), derelict registry and sweep log.
- **Field notes** (`docs/notes.html`): calibration rolls per signaller, cipher quality vs Knowledge, drift log, fast
  jump law, and the hand-written field log.

Exact derelict positions are sent privately by DM to whoever decodes a cipher. This site shows the centre of the
triangle unless the decoder chooses to publish the fix.

## Layout

```
docs/                    GitHub Pages site (static, no build step)
  index.html, notes.html
  assets/                essi.css, survey.js (shared), map.js, notes.js
  data/survey.json       generated by tools/build_survey.py, do not edit
  data/field_notes.json  field log, edited by hand
data/manual.json         public hand-kept intel merged into survey.json
data/private.json        DM decode reports (git-ignored, never published as is)
tools/build_survey.py    archive of #spacecraft messages → docs/data/survey.json
tests/                   offline tests: python3 tests/test_build_survey.py
```

## Updating the survey

1. Capture new channel traffic into the private archive (scanner kept outside this repository).
2. Add a DM decode report if you received one (exact position stays private unless `"public": true`):
   `python3 tools/build_survey.py --archive <archive.json> --add-dm report.txt`
3. Rebuild: `python3 tools/build_survey.py --archive <archive.json>`
4. Write any new finding in `docs/data/field_notes.json`.
5. `git commit -am "Survey update" && git push`: GitHub Pages serves `docs/` from `main`.

Preview locally: `python3 -m http.server 8765 --directory docs`, then open http://localhost:8765.
